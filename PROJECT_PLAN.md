## Технические заметки на память
- Приложение собирается в Android Studio (Kotlin + Jetpack Compose).
- Картинки ищутся в `assetsui` через `AssetImage.kt`.
- Если картинки нет, показывается темная заглушка (приложение не падает).
- Для изменения размеров картинок на экране создания персонажа нужно смотреть `fillMaxHeight(0.44f)` в `CharacterCreationScreen.kt`.
